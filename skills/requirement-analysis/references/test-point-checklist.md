# 测试点维度检查清单

提取完测试点后,逐条对照本清单自查遗漏。不是每个维度都适用所有功能点,
但**适用而没覆盖**的维度必须说明原因。

## 输入校验
- [ ] 必填项为空 / 全空格 / 仅特殊字符 / 前后空格(是否 trim)
- [ ] 长度:最小、最小-1、最大、最大+1
- [ ] 数值:0、负数、小数精度、超大数(溢出)、千分位/货币格式输入
- [ ] 格式:手机号/邮箱/身份证/URL 等合法与非法格式;大小写敏感性(邮箱、用户名)
- [ ] 特殊字符:Emoji、SQL 注入串(`' OR 1=1 --`)、XSS 串(`<script>`)、全角字符、
  换行符、超长字符串(10w+)
- [ ] 粘贴板注入:粘贴带空格/换行/非法字符的内容
- [ ] 重复数据:已存在的唯一键(用户名、订单号)重复提交
- [ ] 枚举值:合法枚举之外的值(接口直接传非法枚举)

## 业务流程
- [ ] 主流程(基本流)端到端走通
- [ ] 每个分支点(备选流)至少一条测试点
- [ ] 流程逆操作:提交后撤销、支付后退款、发布后下线
- [ ] 流程中断恢复:中途退出、断网后重进、刷新页面后状态、浏览器回退再提交
- [ ] 重复提交:双击、快速连点、刷新重复提交
- [ ] 幂等性:同一请求重发(网络重试/用户重试)不产生重复数据(重复下单、重复扣款)
- [ ] 事务完整性:多步操作中间失败时,已完成的步骤是否回滚/补偿(如扣款成功但下单失败)

## 权限与安全
- [ ] 未登录访问受保护页面/接口
- [ ] 横向越权:修改请求中的 ID 操作他人数据(订单、地址、文件)
- [ ] 纵向越权:普通用户调用管理员功能/接口
- [ ] 敏感信息(密码、身份证、银行卡、手机号)的显示脱敏
- [ ] 敏感信息不出现在:URL 参数、日志、错误提示、接口多余返回字段中
- [ ] 认证凭证:登录态过期后的操作行为;登出后旧 token 是否立即失效
- [ ] 防枚举:登录/找回密码的失败提示不区分"账号不存在"与"凭证错误"
- [ ] 验证码/短信:暴力破解(错误次数限制)、有效期、一次性使用
- [ ] 文件类:上传可执行文件、路径穿越(../)、下载他人文件

## 并发与时序
- [ ] 同账号多端同时操作同一数据
- [ ] 库存/余额类:并发扣减不超卖、不为负
- [ ] 定时任务与用户操作同时发生
- [ ] 临界时间:跨零点、跨月、活动开始/结束瞬间、超时边界(如 29:59 与 30:00)
- [ ] 消息乱序/重复:异步回调(支付结果通知)乱序到达、重复到达
- [ ] 会话并发:同账号两处登录的处理(互踢/共存)

## 数据一致性
- [ ] 新增/修改/删除后,列表页、详情页、统计页数据同步
- [ ] 关联数据:删除被引用的基础数据(如删除有订单的商品分类)
- [ ] 大数据量:空列表、单条、分页边界(第 1 页/最后 1 页/超出页码)、深翻页(第 1000 页)
- [ ] 排序与筛选:组合条件、无结果、结果跨页、排序字段值相同
- [ ] 统计口径:总数/金额统计与明细之和一致

## 异常与容错
- [ ] 服务端超时 / 500 错误时前端表现(友好提示,不暴露堆栈)
- [ ] 网络中断后重试;弱网下的表现
- [ ] 文件上传:超大文件、错误格式、损坏文件、空文件、同名文件
- [ ] 第三方依赖(短信、支付、地图、OSS)不可用时的降级表现
- [ ] 资源耗尽:磁盘满、连接池耗尽时的行为(如适用)

## 性能与容量(如文档涉及)
- [ ] 文档声明的响应时间指标在典型场景下的验证点
- [ ] 数据量上限:单表大数量级下列表/导出/统计的表现
- [ ] 批量操作上限:批量导入/删除的最大条数及超限行为
- [ ] 导出大数据量:是否异步、超时处理

## 消息与通知(如文档涉及)
- [ ] 触发时机:每个业务事件是否触发对应通知(短信/邮件/站内信/Push)
- [ ] 不重复发送:重试、重复事件不导致重复通知
- [ ] 通知内容:变量替换正确、链接有效、文案与模板一致
- [ ] 免打扰/退订设置生效(如适用)

## 文件与导入导出(如文档涉及)
- [ ] 导入:模板校验、错误行反馈、部分失败处理、重复导入、大文件导入
- [ ] 导出:导出数据与页面查询结果一致、特殊字符(逗号/换行/公式注入 `=cmd`)处理、
  大数据量导出、权限内数据才可导出

## 兼容与体验(如适用)
- [ ] 文档声明的浏览器/操作系统/机型范围
- [ ] 文案:成功/失败提示语与文档一致、无错别字、变量正确替换
- [ ] 布局:长文案截断/换行、数字千分位、金额格式化、时区显示
- [ ] 埋点/日志类需求(若文档提及)
